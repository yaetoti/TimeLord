# TimeLord

A 2D platformer game about a Time Guardian who must stop the enemies and protect the Time Artifact. Developed for "Indie Game Dev Beginners #002" (2022) in 3 days

Available at [itch.io](https://omnir.itch.io/timelord)

Features
- Weapons: knife, crossbow
- Time reiwind mechanics (character, animations, projectiles, enemies). Incorporates a custom system that allows creating and restoring data snapshots and control time speed
- Enemies: rats, bats
- Level transitions
